# L3 — Comments on notes (done 2026-11-01)

**Decided with David (2026-11-01):** kept **beside the note** (their own table), anchored to quoted
words and shown in the side panel; never in the Markdown. Exports carry them as a separate file per
note (`.comments/<path>.md`); backups and restores keep them.

**How it works:** `src/comments.ts` and `web/lib/comments.ts`. A thread starts on the selected words:
the browser makes Yjs relative positions for their start and end from the live text, so the mark
follows the words as anyone types around them (an outside write, such as an agent's, is merged as one
changed span, so a comment inside a span it rewrites loses its place and stays in the panel). The
editor marks open threads (`cm-commented`); replies hang off a thread; editors and owners comment and
resolve, viewers read; only a comment's writer can change its words. A comment tells the note's
writer, a reply the thread's starter, and `@Name` anyone named (F39), each person once. Changes reach
open pages through the collection's event stream (`comments.changed`).
