# F23 — One vault list on the Mac: Mac vaults and cloud vaults together (done 2026-10-30, commits 5e34de7 and 5c3285a)

The design as planned, kept for reference. What was built differs in small ways, noted at the end.

## The plan

**Size** L · **Evidence** decided 2026-10-25 (option A over keeping the laptop kit separate);
the first step of L8's desktop app, and a narrow first answer to L6 (federation).

The Mac Commonplace holds its Mac vaults itself and signs in to the cloud with a **device token**
(revocable, in Settings → Connections; L8 step 4) for the cloud vaults. One switcher shows both,
grouped. **Move to Mac** and **Move to cloud** reuse copy-and-move between vaults
(`src/between.ts`, v0.0.49) across the two servers: notes, attachments, types and history, the
original to Trash. The iPhone sees only cloud vaults. Offline, cloud vaults behave as F4 does
today and Mac vaults carry on as normal.

**Done when** one switcher shows Mac and cloud vaults, a note and a folder move each way with
Undo, the token can be revoked, and a cloud vault's live editing works from the Mac app as it
does from the browser.

## What was built

- **Sign-in:** the cloud's own OAuth (F25) with a `device` scope, which mints `cpd_` tokens; the
  scope isn't advertised (MCP clients ask for every scope offered) and is granted only when
  asked for alone. Listed in the cloud's Settings → Connections → *Macs signed in*; signing out
  there closes the Mac's sockets at once (they go by the token's row, since access tokens rotate).
- **A proxy, not two origins:** the browser only talks to the Mac, which forwards requests,
  events and the live socket for cloud collections. The CSP, cookies, the service worker and
  offline copies needed no second origin.
- **Ids:** each cloud collection gets an id from the Mac's vaults sequence, without a vaults row,
  so nothing local (MCP, the AI, backups) can touch it.
- **Moving:** a cross-server send is a bundle from one side and a receive on the other
  (`src/between.ts`), so the report and Undo are the same as within one server. The note keeps
  its history; revisions take the receiving person as author.
- **Not built:** separate "Move to Mac / Move to cloud" commands (the existing *Move to another
  collection…* lists both); members' changes, renaming, publishing and GitHub for cloud
  collections from the Mac (done in the cloud). A token revoked while a socket is open is caught
  by sign-out, not by expiry. The browser test signs the test server in to itself, which
  covers the screens and the consent flow; the e2e suite drives two servers.
